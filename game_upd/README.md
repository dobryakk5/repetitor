# Занимательная Грамматика

Интерактивный сборник игр и загадок по русскому языку на основе книги
**А. Т. Арсирий, Г. М. Дмитриева «Материалы по занимательной грамматике русского языка»** (Учпедгиз, 1963).

## Запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # статическая сборка
```

## Архитектура

```
grammar-games/
├── data/
│   ├── types.ts          # TypeScript-типы + константы разделов и типов игр
│   └── games.ts          # все 20 игр; getGame(), getRelated()
│
├── components/
│   ├── Badges.tsx         # SectionBadge, TypeBadge — server, без состояния
│   ├── AnswerButton.tsx   # 'use client' — кнопка "показать/скрыть ответ"
│   ├── ItemsList.tsx      # 'use client' — список заданий с кнопкой "показать все"
│   ├── RiddlesList.tsx    # server — список загадок (AnswerButton внутри — client)
│   ├── QuizList.tsx       # server — список вопросов викторины
│   ├── CrosswordView.tsx  # 'use client' — кроссворд с раскрытием по клику
│   └── GameFilters.tsx    # 'use client' — фильтры + карточки на главной
│
└── app/
    ├── layout.tsx          # server — шрифты, метадата
    ├── globals.css         # базовые стили + анимации
    ├── page.tsx            # server — герой + <GameFilters>
    ├── not-found.tsx       # 404
    └── game/[id]/
        └── page.tsx        # server — generateStaticParams, рендер игры
```

### Ключевые решения

**Server / Client разделение**
- Страницы (`app/`) — серверные компоненты: читают данные, рендерят HTML
- Интерактивные части (`AnswerButton`, `ItemsList`, `GameFilters`, `CrosswordView`) — клиентские острова (`'use client'`)
- `RiddlesList` и `QuizList` — серверные, но используют `AnswerButton` (client) внутри: Next.js автоматически гидрирует нужные части

**`generateStaticParams`** в `game/[id]/page.tsx` — все страницы игр генерируются при `npm run build` как статические HTML. Деплой на Vercel или GitHub Pages без сервера.

**`data/` вне `app/`** — данные это не UI. Импортируются и в серверные страницы, и при необходимости в клиентские компоненты.
