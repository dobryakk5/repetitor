# Лендинг TutorTrack

Главная страница frontend (`/`) описывает сервис для репетитора и ведет пользователя к регистрации.

## Основной посыл

TutorTrack помогает репетитору фиксировать уроки, видеть слабые темы, отслеживать повторяющиеся ошибки и готовить отчеты для родителей без ручных таблиц.

## Структура страницы

1. Hero-блок: что делает сервис и для кого.
2. Визуальный mock dashboard: прогресс, динамика, сильные/слабые темы, повторяющиеся ошибки.
3. Ценность: меньше ручной рутины, больше прозрачности для родителей, фокус на повторении.
4. Возможности: ученики, уроки, темы, ошибки, домашние задания, отчеты, tenant isolation.
5. Сценарий работы: ученик → урок → аналитика → отчет.
6. Для кого: частный репетитор или небольшая команда.
7. Финальный CTA: регистрация и вход.

## Публичные маршруты

- `/` — лендинг;
- `/login` — вход;
- `/register` — регистрация.

Остальные страницы закрыты через `AppAuthBoundary`.
