## 📄 Описание файлов

### Frontend файлы

#### 1. **index.html** (Главная страница)
- ✨ Карточки всех доступных тестов
- 🏆 Таблица лидеров (leaderboard)
- 📊 Общая статистика
- 🔄 Автоматическая загрузка результатов из persistent storage

**Технологии:** HTML5, CSS3, JavaScript, Persistent Storage API

#### 2. **sentence_check.html** (Страница теста)
- 📝 12 вариантов предложений для разбора
- ✅ Проверка частей речи и членов предложения
- 🎯 Морфологический разбор слов
- 💾 Модальное окно для сохранения результатов
- 📈 Статистика прогресса
- ← Кнопка возврата на главную

**Технологии:** HTML5, CSS3, JavaScript

---

### Database файлы

#### 3. **database_schema.sql** (Схема БД)

**Включает:**
- 🗃️ **8 таблиц:**
  - `users` - Пользователи
  - `test_types` - Типы тестов
  - `test_variants` - Варианты тестов
  - `test_attempts` - Попытки прохождения
  - `user_statistics` - Статистика пользователей
  - `leaderboard` - Таблица лидеров
  - `achievements` - Достижения
  - `user_achievements` - Достижения пользователей

- 🔄 **4 функции:**
  - `update_user_statistics()` - Обновление статистики
  - `update_leaderboard()` - Обновление leaderboard
  - `update_leaderboard_ranks()` - Обновление рангов
  - `update_user_last_active()` - Обновление активности

- ⚡ **3 триггера:**
  - Автоматическое обновление статистики
  - Автоматическое обновление leaderboard
  - Автоматическое обновление last_active

- 📊 **4 представления (views):**
  - `v_top_users` - Топ пользователей
  - `v_user_detailed_stats` - Детальная статистика
  - `v_leaderboard_detailed` - Leaderboard с именами
  - `v_recent_attempts` - Последние попытки

#### 4. **test_data.sql** (Тестовые данные)

**Включает:**
- 📝 12 вариантов предложений с правильными ответами
- 👥 5 тестовых пользователей
- 📊 Тестовые результаты для демонстрации
- 🏆 Автоматическое обновление leaderboard

**Предложения разной сложности:**
- Easy: 4 варианта (простые предложения)
- Medium: 5 вариантов (средней сложности)
- Hard: 3 варианта (сложные предложения)

## 🎯 Быстрый старт

### 1. Frontend (работает сразу)
```bash
# Просто откройте файлы в браузере
open index.html
```

### 2. Database (требует установки PostgreSQL)
```bash
# Создайте базу данных
psql -U postgres -c "CREATE DATABASE russian_tests_db;"

# Выполните скрипты
psql -U postgres -d russian_tests_db -f database_schema.sql
psql -U postgres -d russian_tests_db -f test_data.sql
```

## 📝 Примеры использования

### Сценарий 1: Новый пользователь
1. Открывает `index.html`
2. Видит список тестов и пустой leaderboard
3. Нажимает на "Разбор предложения"
4. Проходит вариант 1, получает 8/10
5. Вводит имя "Анна" и сохраняет
6. Возвращается на главную
7. Видит себя в leaderboard: Анна | 8/10 | 80%

### Сценарий 2: Продвинутый пользователь
1. Открывает `index.html`
2. Видит свои предыдущие результаты
3. Проходит несколько вариантов подряд
4. Результаты накапливаются
5. Поднимается в рейтинге

### Сценарий 3: Администратор
1. Подключается к PostgreSQL
2. Выполняет запросы из `API_DOCUMENTATION.md`
3. Анализирует статистику
4. Находит сложные варианты
5. Корректирует контент
