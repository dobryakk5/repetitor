## 🚀 Быстрая установка

### Шаг 1: Скопируйте файлы в ваш проект

```bash
# Перейдите в папку вашего проекта
cd your-project

# Скопируйте компоненты
cp morfolab-games/components/MorphemeAnalysisGame.tsx components/
cp morfolab-games/components/MorphemeAnalysisLevel2.tsx components/

# ВАЖНО: Сначала сделайте резервную копию!
cp app/page.tsx app/page.tsx.backup

# Замените главную страницу
cp morfolab-games/app/page.tsx app/
```

### Шаг 2: Проверьте зависимости

```bash
# Убедитесь, что установлены все необходимые пакеты
npm install framer-motion @dnd-kit/core
```

### Шаг 3: Запустите проект

```bash
npm run dev
```

## 🎨 Цветовая схема морфем

- 🟦 **Приставка** (prefix): `#3B82F6` (синий) → 
- 🟩 **Корень** (root): `#10B981` (зелёный) ■
- 🟧 **Суффикс** (suffix): `#F59E0B` (оранжевый) ▲
- 🟥 **Окончание** (ending): `#EF4444` (красный) ●

## ⚠️ Возможные проблемы и решения

### Проблема 1: Ошибки импорта

**Ошибка:**
```
Cannot find module '../components/MorphemeAnalysisGame'
```

**Решение:**
Проверьте пути импорта в `app/page.tsx`. Они должны соответствовать вашей структуре:
```typescript
import MorphemeAnalysisGame from '../components/MorphemeAnalysisGame';
import MorphemeAnalysisLevel2 from '../components/MorphemeAnalysisLevel2';
```

Если у вас компоненты в другой папке, измените путь, например:
```typescript
import MorphemeAnalysisGame from '@/components/MorphemeAnalysisGame';
```

### Проблема 2: TypeScript ругается на типы

**Ошибка:**
```
Property 'type' does not exist on type 'Morpheme'
```

**Решение:**
Убедитесь, что в `types/morphology.ts` есть правильные экспорты:
```typescript
export interface Morpheme {
  id: string;
  text: string;
  type: 'prefix' | 'root' | 'suffix' | 'ending';
  // ... остальные поля
}
```

### Проблема 3: Не работает drag & drop в первой игре

**Решение:**
Убедитесь, что компоненты `MorphemeCard`, `ConstructionZone`, и другие существуют и правильно импортированы в главной странице.

### Проблема 4: Стили не применяются

**Решение:**
Проверьте, что Tailwind CSS настроен в `tailwind.config.js`:
```javascript
module.exports = {
  content: [
    './app/**/*.{js,ts,jsx,tsx}',
    './components/**/*.{js,ts,jsx,tsx}',
  ],
  // ...
}
```

## 📝 Дополнительная настройка

### Изменить количество очков:

В файлах `MorphemeAnalysisGame.tsx` и `MorphemeAnalysisLevel2.tsx` найдите:
```typescript

```
Измените `10` на нужное значение.

В начале каждого файла есть массив `WORDS_TO_ANALYZE` или `WORDS_TO_ANALYZE_LEVEL2`. Добавьте свои слова по примеру существующих.

В массиве `MORPHEME_TYPES` в каждом файле измените значения `color`.
