# 🎲 Занимательная Грамматика — Сборник игр

Интерактивный веб-сборник игр, загадок и заданий по русскому языку  
на основе книги **А. Т. Арсирий и Г. М. Дмитриева «Материалы по занимательной грамматике русского языка»** (Учпедгиз, 1963).

## 🚀 Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## 📚 Что включено

### Фонетика (7 игр/загадок)
- **Логогрифы** — загадки на добавление/замену звука
- **Кто скорее?** — командная игра на буквы и звуки  
- **Одним словом** — игра на двойные согласные
- **Буквы Е, Н, И, Е** — загадки о многозначных буквах
- **Глухие и звонкие** — загадки-шутки с парными согласными
- **Ударение** — загадки, где ударение меняет смысл
- **Викторина по фонетике** — 8 вопросов-ответов

### Морфология (8 игр)
- **Родственные слова** — найди лишнее/однокоренное
- **Тайны словаря** — угадай слово по тильде
- **Шарады** — стихотворные загадки
- **Чайнворды** — цепочки слов (существительные, прилагательные)
- **Полминутки для шутки** — загадки о глаголах
- **Викторина к кружку** — состав слова
- **Знаете ли вы...** — факты о наречиях
- **Вопросы к викторине** — морфология

### Лексика (8 игр)
- **Угадай омоним** — игра «Уточни одним словом»
- **Уточни одним словом** — пары омонимов с уточнением  
- **Кроссворд «Синонимы»** — 10 горизонтальных + 10 вертикальных
- **Равнобуквенные синонимы** — синонимы с одинаковым количеством букв
- **Спрятанные слова** — найди слово по первым буквам
- **Загадки с антонимами** — загадки и задания
- **Игры в слова** — буриме, анаграммы, наборщик, города
- **Загадки-шутки** — многозначность слов

## 🛠 Технологии

- **Next.js 14** (App Router)
- **TypeScript**
- **Tailwind CSS**
- Google Fonts: Playfair Display, IM Fell English, Martel

## 🎨 Дизайн

Vintage-эстетика советского учебника: пергаментные тона, шрифты с засечками,  
орнаментальные элементы и тёмно-красные акценты.
