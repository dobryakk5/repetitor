# 🧪 МорфоЛаб - Игра-конструктор слов

![Version](https://img.shields.io/badge/version-1.0.0-blue)
![Next.js](https://img.shields.io/badge/Next.js-14-black)
![TypeScript](https://img.shields.io/badge/TypeScript-5.3-blue)

**Интерактивная обучающая игра для изучения морфологии русского языка**

---

## 🎮 Концепция

МорфоЛаб - это образовательная игра-конструктор, где дети собирают слова из морфем (приставка, корень, суффикс, окончание), используя drag-and-drop механику.

### Ключевые особенности:

- 🧩 **Физическая логика соединения** - морфемы стыкуются только если грамматически подходят
- 🎨 **Визуальная дифференциация** - каждый тип морфемы имеет уникальную форму и цвет
- 📚 **Образовательный контент** - каждая морфема содержит объяснение значения
- 🎯 **10 уровней** от простого к сложному
- 🏆 **Система достижений** с подсчётом очков

---

## 🎯 Игровые режимы

### 1. Кампания (реализовано)
- 10 прогрессивных уровней
- От простых слов (корень + окончание) до сложных (4-5 морфем)
- Подсказки для каждого уровня

### 2. Экзамен (в планах)
- Дается значение слова
- Нужно собрать правильное слово

### 3. Хардкор (в планах)
- Можно собирать несуществующие слова
- ИИ объясняет, почему слово не работает

### 4. Песочница (в планах)
- Свободная игра со всеми морфемами
- Создание своих слов

## 🎨 Визуальная система

### Типы морфем и их формы:

| Тип | Форма | Цвет | Иконка |
|-----|-------|------|--------|
| Приставка | Стрелка → | Синий #3B82F6 | → |
| Корень | Прямоугольник ■ | Зелёный #10B981 | ■ |
| Суффикс | Трапеция ▲ | Оранжевый #F59E0B | ▲ |
| Окончание | Круг ● | Красный #EF4444 | ● |

### Пример сборки слова:

```
[по] → [лет] ■ [∅] ●  =  "полет"
```

## 🔧 Алгоритм проверки слова

```typescript
function checkWord(construction: Morpheme[]): WordConstruction {
  // 1. Собираем текст слова
  const word = construction.map(m => m.text === '∅' ? '' : m.text).join('');
  
  // 2. Проверяем в словаре
  const validWord = VALID_WORDS[word];
  
  // 3. Проверяем порядок морфем
  const isValidOrder = validateMorphemeOrder(construction);
  
  // 4. Проверяем грамматические правила
  const isGrammaticallyCorrect = checkGrammar(construction);
  
  return {
    morphemes: construction,
    isValid: validWord && isValidOrder && isGrammaticallyCorrect,
    word: word,
    meaning: validWord?.meaning,
    explanation: generateExplanation(word, validWord)
  };
}
```

## 🎮 Игровая механика

### Drag and Drop

1. **Перетаскивание** - возьми морфему из библиотеки
2. **Валидация** - система проверяет возможность соединения
3. **Соединение** - морфема добавляется в конструкцию
4. **Проверка** - собранное слово проверяется на правильность

### Правила соединения:

```typescript
// Приставка → только перед корнем
prefix.canAttachRight = ['root']

// Корень → может иметь приставку слева, суффикс справа
root.canAttachLeft = ['prefix']
root.canAttachRight = ['suffix', 'ending']

// Суффикс → только между корнем и окончанием
suffix.canAttachLeft = ['root']
suffix.canAttachRight = ['ending']

// Окончание → только в конце
ending.canAttachLeft = ['root', 'suffix']
ending.canAttachRight = []
```
