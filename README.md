## 🎮 Как работает leaderboard

### Механизм работы:

1. **После успешного прохождения варианта:**
   - Появляется модальное окно с предложением ввести имя
   - Пользователь вводит имя и нажимает "Сохранить результат"

2. **Сохранение данных:**
   - Данные сохраняются в `window.storage` (persistent storage)
   - Ключ: `leaderboard:{имя_пользователя}`
   - Данные хранятся как shared (доступны всем пользователям)

3. **Формат данных:**
```javascript
{
  name: "Имя пользователя",
  correct: 45,      // Всего правильных ответов
  total: 60,        // Всего вопросов
  accuracy: 75.0,   // Процент правильных ответов
  lastUpdated: "2026-02-03T12:00:00.000Z"
}
```

4. **Накопительная статистика:**
   - Если пользователь проходит несколько вариантов, его результаты суммируются
   - Точность пересчитывается на основе общего количества правильных/неправильных ответов

5. **Отображение на главной странице:**
   - Таблица сортируется по проценту правильных ответов (accuracy)
   - Топ-3 выделены цветами: 🥇 золото, 🥈 серебро, 🥉 бронза

## 🔧 Для добавления новых тестов

### Структура для нового теста:

1. **Создайте новый HTML файл** (например, `orthography_test.html`)
2. **Добавьте карточку на главной странице** (`index.html`):
```html
<a href="orthography_test.html" class="test-card">
    <div class="test-icon">🔤</div>
    <div class="test-title">Орфография</div>
    <div class="test-description">
        Проверьте знание правил написания слов
    </div>
    <div class="test-status">
        <span>Не начато</span>
    </div>
</a>
```

3. **Интегрируйте leaderboard** в новый тест:
   - Скопируйте модальное окно из `sentence_check.html`
   - Скопируйте функции: `showNameModal()`, `saveToLeaderboard()`, `closeNameModal()`
   - При успешном завершении теста вызовите `showNameModal(correct, total)`

## 💾 Технические детали

### Persistent Storage API:
```javascript
// Сохранение
await window.storage.set(key, value, shared);

// Получение
const result = await window.storage.get(key, shared);

// Список ключей
const result = await window.storage.list(prefix, shared);
```

### Параметры:
- `key`: уникальный идентификатор (до 200 символов)
- `value`: строка (до 5MB)
- `shared`: `true` для общего доступа, `false` для личного

## ⚠️ Важные замечания

- Leaderboard использует shared storage - все результаты видны всем пользователям
- Данные привязаны к имени пользователя - используйте уникальные имена
- Persistent storage работает только в поддерживаемых средах (например, Claude Artifacts)
- При ошибках сохранения проверьте консоль браузера
